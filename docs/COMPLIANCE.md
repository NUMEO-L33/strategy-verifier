# 컴플라이언스 경계 분석 (세션 D)

작성일: 2026-08-01. 이 문서는 엔지니어링 측 경계 설계와 그 근거의
기록이며 법률 자문이 아니다. 실판매 전 대한민국 변호사 검토 1회를
권고 사항으로 기록한다.

## 1. 이 제품이 하는 것의 법적 성격 규정

제품은 사용자가 스스로 진술한 기계적 주장("이 조건이면 이 방향")을
과거 공개 데이터 위에서 통계적으로 판정하는 소프트웨어 도구다.
백테스트 라이브러리와 같은 범주이며, 다음을 하지 않는다:

- 특정 금융투자상품의 가치 평가 또는 매수·매도 판단의 제공
- 개별 이용자 상황에 맞춘 투자 판단의 조언
- 매매 신호의 생성, 자동 주문, 계좌 접근 (코드 경로 자체가 부재하며
  safety-review 스캔이 상시 확인)
- 미래 수익에 대한 어떤 형태의 진술

판정문의 두 결과는 모두 과거형·통계형 진술이다: CONFIRMED 는 "등록된
기준을 과거 창에서 넘었음"이고 NOT_CONFIRMED 는 "이 기준·이 표본에서
미확인"이다. 어느 쪽도 장래 손익에 대한 의견이 아니다.

## 2. 경계의 코드 강제 현황

- 매매·주문·계좌 경로 부재: safety-review 가 전 소스 스캔
- 모든 제품 리포트에 연구 전용 문구와 무자문 문구 상시 출력
- 진단 층은 처방 금지 설계: 파라미터 튜닝 권고·다음 수 제시 없음
- 등식 스탬프: 결과가 시장·기법·주문의 결정적 함수임을 해시로 증명

## 3. 잔여 위험과 운영 규칙

a) 마케팅 문구: 다음 표현을 어떤 채널에서도 사용하지 않는다 —
"수익 보장", "승률 보장", "추천 종목", "매수/매도 타이밍",
"따라하면 번다" 류. 허용 프레임은 "주장 검증 도구", "사망진단서 또는
생존확인서", "과거 데이터 위의 심판" 이다.

b) 콘텐츠 채널(기법 부검 등)을 운영할 경우: 특정 상품에 대한 판단을
불특정 다수에게 제공하는 외형이 되면 유사투자자문업 신고 요건 검토가
필요해진다. 콘텐츠는 "특정 코인을 사라/팔라"가 아니라 "이 조건
주장이 데이터를 통과했는가"의 형식을 유지한다.

c) 판정 결과의 인용: 구매자가 CONFIRMED 판정을 수익 보장처럼 재인용
하는 것을 라이선스로 금지한다(LICENSE 4항).

## 4. 상태 판독(verify-read) 조항

판독은 서술 전용이다: 사용자가 스스로 정의한 규칙의 성립 지점과 그
과거 결과, 최신 봉의 조건 상태만을 표시하며, 진입·목표가·손절·추천에
해당하는 어떤 표현도 출력에 존재하지 않는다(테스트로 부재를 고정).
모든 판독 출력에는 해당 가족의 판정 상태가 강제로 부착되며,
미판정이면 UNADJUDICATED 배너가 표시된다. 판독은 배치·결정적이며
등식 스탬프가 붙는다. 실시간 스트림·알림은 v2 로 이관한다
(대기열의 UI 이후 순번). 자사 제작 기법의 동봉·추천
라이브러리 형태 배포를 금지하고, 마케팅 금지어에 "시그널"을
추가한다(허용 용어: 상태 판독, 성립 지점).

### 4a. 워크스페이스 채팅 조항

채팅은 사실 패킷(감지 실측치·최신 봉 상태·판정문·통계)만을 근거로
서술한다. LLM 은 선택 사항이며(VERIFIER_LLM_KEY 설정 시), 모델
출력은 예외 없이 서버측 어휘 필터를 통과한다: 지시 어휘 또는 현재
자리 평가가 검출되면 응답 전체가 고정 경계 문구로 치환된다. 모델
출력의 모든 수치는 사실 패킷 또는 질문에 실재해야 하며, 패킷에
없는 수치(파생 계산 포함)가 검출되면 응답을 폐기하고 결정론
응답으로 강등한다(모드 grounded 로 표기). 경계는
모델의 약속이 아니라 코드다. 키 부재·전송 실패 시 결정론 응답으로
강등되어 오프라인에서도 동작한다. 채팅 로그는 저장하지 않는다.

## 5. 결정 기록 (외부 절차 조항 대체)

2026-08-01, 소유자 결정: 변호사 검토 절차를 제거하고 진행한다. 이에
따라 실판매·실시간 판독의 전제 조건이었던 검토 게이트는 소멸한다.
본 문서·DISCLAIMER·LICENSE 의 실질 조항과 3항의 마케팅 규칙은
그대로 유효하다. 이 결정으로 발생하는 잔여 법적 리스크는 소유자가
인수하며, 본 문서의 작성 주체는 적법성을 보증하지 않는다. 추후
검토를 재도입할 경우 새 커밋으로 기록한다.
